接入 AI 助手

让 Claude Code 和 Codex
帮你记

Noted 自带 MCP 服务。助手连上以后，可以查日程、建待办、写笔记、记打卡和交易。

明天下午三点和王总开会，提前半小时提醒

noted · create_event

已添加：10月11日 周日 15:00「和王总开会」，14:30 提醒你。

  1. 注册用邮箱和密码注册一个账号。
  2. 生成令牌在「我的账号」里给每个助手生成一个，不用了随时吊销。
  3. 粘贴命令Claude Code 在终端运行一行命令，Codex 把配置写进文件。
Claude Code · 终端运行，再在 Claude Code 里输入 /mcp 选 noted 登录
claude mcp add --scope user --transport http noted {{ORIGIN}}/mcp
Codex · ~/.codex/config.toml
[mcp_servers.noted]
url = "{{ORIGIN}}/mcp"
bearer_token_env_var = "NOTED_TOKEN"
Codex · 终端环境变量
export NOTED_TOKEN=<令牌>

把 <令牌> 换成你生成的令牌。在「我的账号」生成时，命令会自动填好。

自己部署

一个程序，一个数据文件

Noted 是单个 Go 程序，数据存在一个 SQLite 文件里。用 Docker 或直接跑二进制，iPhone 应用和 AI 助手都连你自己的服务器。

Docker
git clone https://github.com/liliang-cn/noted && cd noted
docker compose up -d
docker compose run --rm noted user add alice
二进制
make build
./bin/noted user add alice
./bin/noted serve
  • noted user add 创建用户并打印第一个令牌
  • NOTED_AUTH_SIGNUP=true 开放邮箱注册
  • NOTED_MCP_LISTEN 打开这个网页和远程 MCP

在 GitHub 查看源码和部署说明 →
